# Xeero AI Pocket Tutor — Website

Responsive static landing page for Xeero AI Pocket Tutor.

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Choose branch **main** and folder **/(root)**, then Save.
4. Wait for GitHub Pages to publish the site.

Expected URL: https://kasanovah.github.io/xeero-ai-tutor/

The app download link is intentionally omitted until an official public release is available.
